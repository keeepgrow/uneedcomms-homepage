# 📰 유니드컴즈 뉴스룸 업데이트 가이드

> 이 문서는 **개발 지식이 없어도** 홈페이지 뉴스룸에 기사를 추가·수정할 수 있도록 만든 설명서입니다.
> 코드를 설치하거나 터미널을 쓸 필요 없이, **GitHub 웹사이트에서 클릭만으로** 모두 가능합니다.

---

## 🔑 먼저 알아둘 것

- 뉴스룸의 모든 기사는 **`src/data/news.xml`** 이라는 파일 하나에 들어 있습니다.
- 이 파일을 고치고 저장하면 → **1~2분 뒤 홈페이지에 자동으로 반영**됩니다.
  (메인 페이지 하단 뉴스 섹션 + 뉴스룸 서브페이지 모두 동시에 반영돼요.)
- 날짜 기준 **최신순으로 자동 정렬**되므로, 새 기사를 어디에 넣든 상관없습니다.

---

## 🧭 1단계 — 파일 열기

1. 아래 주소로 들어갑니다 (GitHub에 로그인된 상태여야 해요):

   👉 **https://github.com/keeepgrow/uneedcomms-homepage/blob/main/src/data/news.xml**

2. 화면 오른쪽 위의 **연필(✏️) 아이콘**을 클릭합니다.
   → 편집 모드로 바뀝니다.

> 연필 아이콘이 안 보이면, GitHub에 로그인했는지 / 초대를 수락했는지 확인하세요.

---

## ✍️ 2단계 — 기사 추가하기

기사 하나는 아래처럼 **`<article>` 로 시작해서 `</article>` 로 끝나는 한 덩어리**입니다.

```xml
  <article>
    <source>언론사 이름 (한글)</source>
    <source_en>Media name (English)</source_en>
    <date>2026-11-23</date>
    <title>기사 제목 (한글)</title>
    <title_en>Article title (English)</title_en>
    <href>https://기사-링크-주소</href>
  </article>
```

### 넣는 방법
1. 파일 위쪽의 **`<news>` 바로 아랫줄**에 위 덩어리를 복사해 붙여넣습니다.
   (제일 위에 넣는 게 가장 편해요. 어차피 날짜순 자동 정렬됩니다.)
2. 각 항목의 내용을 아래 표대로 채웁니다.

### 각 항목 설명

| 항목 | 뜻 | 예시 |
|------|-----|------|
| `source` | 언론사 이름 (한글) | `머니투데이` |
| `source_en` | 언론사 이름 (영문) | `Money Today` |
| `date` | 기사 날짜 — **반드시 `연도-월-일` 형식** | `2026-11-23` |
| `title` | 기사 제목 (한글) | `유니드컴즈, 신규 서비스 출시` |
| `title_en` | 기사 제목 (영문) | `UneedComms launches new service` |
| `href` | 기사 원문 링크 주소 | `https://...` |

> 💡 **영문(`_en`)을 모르면** 번역기를 돌려 넣거나, 급하면 한글과 같은 내용을 넣어도 됩니다. (영문 홈페이지 방문자에게 그대로 노출됩니다.)

---

## ⚠️ 3단계 — 꼭 지켜야 할 규칙

1. **날짜 형식**은 반드시 `2026-11-23` 처럼 **네 자리-두 자리-두 자리**.
   (`2026.11.23` 이나 `11/23` 은 안 됩니다.)

2. **링크(`href`)가 없으면** 그 줄을 **통째로 지우세요.**
   그러면 제목만 나오고 클릭 링크 없이 표시됩니다.
   ```xml
   <!-- 링크 없는 기사: href 줄을 지우면 됨 -->
   <article>
     <source>보도자료</source>
     <source_en>Press release</source_en>
     <date>2026-11-23</date>
     <title>유니드컴즈 사내 소식</title>
     <title_en>UneedComms internal news</title_en>
   </article>
   ```

3. **특수문자 주의** — 제목에 아래 기호가 들어가면 반드시 바꿔 써야 합니다. (안 바꾸면 홈페이지가 깨질 수 있어요.)

   | 쓰고 싶은 글자 | 대신 입력할 것 |
   |:---:|:---:|
   | `&` | `&amp;` |
   | `<` | `&lt;` |
   | `>` | `&gt;` |

   예) `AI & 커머스` → `AI &amp; 커머스`

4. **`<article>` 과 `</article>` 짝을 반드시 맞출 것.** 하나라도 빠지면 반영이 안 됩니다. (기존 기사 하나를 통째로 복사해서 내용만 바꾸면 실수가 적어요.)

---

## 💾 4단계 — 저장(반영)하기

1. 편집이 끝나면 화면 오른쪽 위의 **초록색 `Commit changes...` 버튼**을 클릭합니다.
2. 작은 창이 뜨면, 맨 아래 **`Commit changes`** 버튼을 한 번 더 누릅니다.
   (설명란은 비워도 되고, `뉴스 추가` 정도로 적어도 됩니다.)
3. 끝! **1~2분 뒤** 홈페이지에 자동 반영됩니다.

### 반영 확인
- 홈페이지: **https://keeepgrow.github.io/uneedcomms-homepage/**
- 바로 안 보이면 **새로고침(Ctrl+Shift+R / ⌘+Shift+R)** 하거나 1~2분 더 기다리세요.

---

## 🔁 실수했을 때 (되돌리기)

- 아직 **Commit 하기 전**이라면 → 그냥 페이지를 나가면 됩니다. (저장 안 됨)
- 이미 **Commit 했는데 잘못됐다면** → 다시 파일을 열어 고치고 또 Commit 하면 됩니다.
- 홈페이지가 안 바뀌거나 이상하면, 보통 **특수문자(`&` 등)** 나 **`<article>` 짝 안 맞음**이 원인입니다. 위 3단계 규칙을 다시 확인하세요.

---

## ✅ 요약 (딱 5줄)

1. `news.xml` 파일 열기 → 연필(✏️) 클릭
2. `<news>` 아랫줄에 `<article>…</article>` 한 덩어리 복사해 붙이기
3. 언론사 / 날짜(`연-월-일`) / 제목 / 링크 채우기
4. 특수문자 `&` `<` `>` 는 `&amp;` `&lt;` `&gt;` 로
5. 초록색 **Commit changes** 두 번 → 1~2분 뒤 홈페이지 반영
